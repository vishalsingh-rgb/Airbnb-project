# Airbnb Clone

## Project Title
Airbnb Clone – Online Room Booking Platform

## Description
This is my final year BCA major project based on an Airbnb Clone.
The project allows users to search, view and book rooms online.
It is developed to understand real-world web application architecture.

## Technologies Used
- HTML
- CSS
- JavaScript
- Rest Api
- Node.js
- Express.js
- MongoDB

## Features
- User Registration & Login
- Property Listing
- Responsive UI
- Room Booking System
- Responsive Design
- Secure Authentication
